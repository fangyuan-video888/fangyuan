# 方源视频助手

一款界面简洁的 Windows 64 位视频解析与下载工具。

## 主要功能

- 支持抖音、快手、哔哩哔哩、YouTube、TikTok、皮皮虾、视频号及红果公开分享片段。
- 支持单链接解析、批量下载和可用清晰度选择。
- 可分别下载视频、MP3 音频、TXT 字幕，也可一键下载三件套。
- 展示平台返回的播放量、点赞、评论与分享数据，缺失项显示“未提供”。
- 内置语音识别模型，无需另行联网下载模型。
- 支持浅色与深色主题、在线更新及作者赞赏。

## 下载与使用

前往本仓库 **Releases** 下载最新版 EXE，无需安装 Python。

复制视频分享链接 → 粘贴到软件 → 开始解析 → 选择清晰度 → 下载。

旧版用户可通过软件内“检查更新”升级。部分平台的备用解析需要 Microsoft Edge；登录要求和可用内容以平台实际返回为准。

## 使用说明

- 视频号暂不支持加密视频；红果仅支持公开分享片段，不支持全集。
- YouTube、TikTok 等平台需要网络能够正常访问。
- 第三方接口返回的数据未独立核验，自动生成的字幕可能存在识别误差。
- 请仅下载自有或已获授权的内容。
